# 🌱 Shrushti Ropvatika — Nursery Website

A modern, responsive website developed for **Shrushti Ropvatika, Ravet, Pune**, as a **real-time client project** to establish and strengthen the organization's online presence.

## 🌐 Live Website

👉 **[Visit Shrushti Ropvatika](https://www.shrushtiropvatika.in/)**

Explore the live website to learn more about the nursery, plants, services, gallery, plant-care information, and contact details.

## 🌿 About

**Shrushti Ropvatika** is a plant nursery based in Ravet, Pune, offering a variety of plants and gardening-related services.

The website allows visitors to:

* Explore plants and categories
* Learn about plant care
* View nursery services and gallery
* Find frequently asked questions
* Access location and contact information
* Browse the website seamlessly on mobile and desktop

## ✨ Key Features

* 🏠 Modern and responsive homepage
* 🌱 Plant categories and details
* 🪴 Plant-care information
* 🛠️ Services section
* 🖼️ Nursery gallery
* ❓ FAQ section
* 📍 Location and contact information
* 📱 Fully responsive design
* ✨ Smooth animations and user-friendly navigation

## 🛠️ Technology Stack

* **React.js**
* **TypeScript**
* **TanStack Start**
* **TanStack Router**
* **Tailwind CSS**
* **Framer Motion**
* **Vite**
* **Nitro**

## 🚀 Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project for production:

```bash
npm run build
```
